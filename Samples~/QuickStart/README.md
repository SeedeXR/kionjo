# Kionjo Quick Start

1. Tools > Kionjo > Build Quick Start Scene. It makes a scene with a stand in rig (a head camera
   and two hand cubes moved by `KionjoSampleRigMover`, which plays the person in the headset) and
   an example storyboard, and opens Window > Kionjo on it.
2. Enter Play mode. Shoot tab: select "Wide shot of the place", press Stage (the debug panel
   hides), then Space to start a take and Space again to stop it.
3. Storyboard tab: Render selected take. The status bar shows the frames.
4. Cut tab: Build draft. The draft folder opens with the MP4, the SRT, a Premiere XML timeline and
   `commands.txt`.

With a real headset, put a Kionjo Recorder on your XR rig instead (Head = the center eye camera,
plus the hand anchors) and switch the rig mover off.
